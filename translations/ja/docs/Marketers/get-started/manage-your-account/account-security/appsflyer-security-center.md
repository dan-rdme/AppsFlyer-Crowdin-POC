> **概要：** AppsFlyerアカウントのセキュリティ関連機能を、1か所で確認・管理できます。

## セキュリティセンターでは何ができますか？

**セキュリティセンター**では、AppsFlyerアカウントのセキュリティ状況をひと目で確認できます。<strong>［セキュリティセンター］</strong>の各セクションのボタンをクリックすると、次の機能にアクセスできます。

| 機能 | 説明 |
| --- | --- |
| <span id="user-management"></span><Anchor target="_blank" href="/marketers/docs/user-management">ユーザー管理</Anchor> | AppsFlyerのユーザーを作成・管理します。必要な機能、アプリ、データにアクセスできるよう、権限を割り当てます。 |
| <span id="redirect-allowlist"></span><Anchor target="_blank" href="/marketers/docs/set-up-your-domain-redirect-allowlist">リダイレクト先の許可リスト</Anchor> | リンクのリダイレクト先として許可するドメインを設定します。 |
| <span id="list-of-authorized-agencies-for-ad-networks"></span><Anchor target="_blank" href="/partners/docs/set-up-your-list-of-authorized-agencies">承認済み代理店のリスト</Anchor>（アドネットワーク向け） | 自社のアドネットワーク連携を使ってキャンペーンを配信できる代理店を管理します。 |
| <span id="api-allowlist"></span><Anchor target="_blank" href="/marketers/docs/set-up-your-api-allowlist">API許可リスト</Anchor> | APIリクエストを許可するIPアドレスを設定します。 |
| <span id="enhanced-login-security"></span>ログインセキュリティの強化 | <Anchor target="_blank" href="/marketers/docs/set-up-sso-authentication-with-your-identity-provider-idp">シングルサインオン（SSO）</Anchor>または<Anchor target="_blank" href="/marketers/docs/implementing-and-using-2fa-login">2要素認証（2FA）</Anchor>を設定し、アカウントへの不正アクセスを防ぎます。 |
| <span id="appsflyer-api-and-s2s-tokens"></span><Anchor target="_blank" href="/marketers/docs/managing-appsflyer-tokens">AppsFlyerトークン</Anchor> | AppsFlyerトークンを使って、APIやS2Sの呼び出しを認証します。トークンを管理し、定期的に切り替えることで、安全性を高めます。 |
| <span id="audit-log"></span><Anchor target="_blank" href="/marketers/docs/audit-log">監査ログ</Anchor> | ログイン、ユーザー管理、API呼び出しなど、アカウント内の操作を確認し、不正アクセスを特定します。 |

[![new-security-center.jpg](https://files.readme.io/7e67e2d954ebaef755a63360a2f2a20983cbd4617383aca9e32a7efd083263ba-51409516770705.jpg)](https://files.readme.io/7e67e2d954ebaef755a63360a2f2a20983cbd4617383aca9e32a7efd083263ba-51409516770705.jpg)

**セキュリティセンターを開くには、次の手順に従います。**

* 上部のバーでアカウントメニュー（メールアドレスのドロップダウン）を開き、<strong>［セキュリティセンター］</strong>を選択します。
