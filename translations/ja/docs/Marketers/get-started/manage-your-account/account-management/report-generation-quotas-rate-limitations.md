> **概要：** Pull APIとデータエクスポートページでは、1日に生成できるレポート数に上限（レート制限）が設けられています。

## レポートのレート制限

1日に生成できるレポート数には、レポートの種類ごとに上限があります。上限は契約プランによって異なります。

**基本ルール：**

* **代理店**：Pull APIの上限は、代理店と広告主で別々に設定されています。いずれも、レポートごと、1日ごと、アプリごとに同じ方式で適用されます。データエクスポートページのレポートについても、代理店と広告主で別々に上限が設定されています。上限に達することが多い場合は、担当営業にお問い合わせください。
* **アドネットワーク**：アドネットワークが生成したレポートは、広告主の上限にはカウントされません。
* **1日の区切り**：上限は、UTCの00:00から始まる暦日ごとに適用されます。

### 集計レポートと分析レポート

| データ取得ツール | 上限 |
| --- | --- |
| Pull APIの集計データ | <ul><li>対象期間が2日以内の場合：<ul><li>アプリ・レポートごとに、1分あたり最大1回の呼び出し</li></ul></li><li>対象期間が3日以上の場合、呼び出しの上限は次のとおりです。<ul><li>アカウントごとに、1日あたり最大120回</li><li>アプリごとに、1日あたり24回</li></ul></li></ul> |
| 集計データのエクスポートページ | 制限なし |
| Master API | 制限なし |
| Cohort API | アカウントごとに、1分あたり60回 |
| SKAN集計レポート | アカウントごとに、1分あたり10回 |

### ローデータ

* Pull APIとローデータのエクスポートページには、それぞれ別の上限が適用されます。
* Pull APIの上限は、代理店と広告主で別々に設定されています。代理店が生成したレポートは、広告主の上限にはカウントされません。ただし、代理店が自社のAPIトークンではなく広告主のAPIトークンを使用した場合、広告主からのリクエストと区別できないため、広告主の上限にカウントされます。データエクスポートページのレポートについても、代理店と広告主で別々に上限が設定されています。
* Pull APIの上限は、次の単位で適用されます。
  * レポート
  * 日
  * アプリ単位
  * アカウント単位
* 広告主の上限は、AppsFlyerの契約プランによって異なります。**注意**：有料プランが必要なレポートにも、上限が適用されます。
* アドネットワークのポストバックレポートの1日あたりの上限は、次の表のとおりです。

具体例については、表の後のよくある質問を参照してください。

#### アドネットワークのポストバックレポートの1日あたりの上限

アドネットワークは、次の種類のポストバックレポートを取得できます。

| ポストバックの分類 | レポートの種類  <br />（上限は種類ごとに別々に適用） | アプリ単位の1日あたりの上限 | アカウント単位の1日あたりの上限 |
| --- | --- | --- | --- |
| アトリビューションのポストバック | <ul><li>インストール</li><li>リターゲティングコンバージョン</li></ul> | 24 | 120 |
| アプリ内イベントのポストバック | <ul><li>アプリ内イベント</li><li>リターゲティングのアプリ内イベント</li></ul> | 12 | 60 |

#### **FAQ**

* Q：あるアプリについて、Pull APIでオーガニックインストールのレポートを24件生成し、さらにローデータのエクスポートページでも24件生成できますか？  
  A：はい。上限は、レポート取得ツールごとに別々に設定されています。
* Q：あるアプリについて、ローデータのエクスポートページで、オーガニックインストール、非オーガニックインストール、リターゲティングコンバージョンのレポートをそれぞれ24件ずつ生成できますか？  
  A：はい。上限は、レポートの種類ごとに別々に設定されています。
* Q：アカウントに25個のアプリがあります。各アプリでオーガニックインストールのレポートを10件ずつ生成できますか？  
  A：いいえ。合計250件となり、アカウント単位の上限である120件を超えるためです。
* Q：代理店が生成したPull APIレポートは、広告主の上限にカウントされますか？  
  A：いいえ。 Pull APIの上限は、代理店と広告主で別々に設定されています。代理店が生成したレポートは、広告主の上限にはカウントされません。ただし、代理店が自社のAPIトークンではなく広告主のAPIトークンを使用した場合は、広告主からのリクエストとしてカウントされます。
