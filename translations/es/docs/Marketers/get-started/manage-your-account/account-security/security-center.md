> **De un vistazo:** Revise y gestione el estado de todas las funciones de seguridad de su cuenta de AppsFlyer desde un solo lugar.

## ¿Qué puedo hacer desde el Centro de Seguridad?

El **Centro de Seguridad** le proporciona una visión general inmediata del estado de seguridad de su cuenta de AppsFlyer. Haga clic en el botón de cualquier sección del **Centro de Seguridad** para acceder a las siguientes funciones:

| Función | Descripción |
| --- | --- |
| <span id="user-management"></span><Anchor target="_blank" href="/marketers/docs/user-management">Gestión de usuarios</Anchor> | Cree y administre los usuarios de AppsFlyer. Asígneles permisos para acceder a las funciones, aplicaciones y datos que necesiten. |
| <span id="redirect-allowlist"></span><Anchor target="_blank" href="/marketers/docs/set-up-your-domain-redirect-allowlist">Lista de redireccionamiento permitido</Anchor> | Defina los dominios permitidos para redirecciones de enlaces. |
| <span id="list-of-authorized-agencies-for-ad-networks"></span><Anchor target="_blank" href="/partners/docs/set-up-your-list-of-authorized-agencies">Lista de agencias autorizadas</Anchor> (para redes publicitarias) | Gestione qué agencias están autorizadas para ejecutar campañas a través de su integración de red. |
| <span id="api-allowlist"></span><Anchor target="_blank" href="/marketers/docs/set-up-your-api-allowlist">Lista de API permitidas</Anchor> | Defina las direcciones IP permitidas para solicitudes de API. |
| <span id="enhanced-login-security"></span>Seguridad de inicio de sesión mejorada | Configure el <Anchor target="_blank" href="/marketers/docs/set-up-sso-authentication-with-your-identity-provider-idp">inicio de sesión único (SSO)</Anchor> o la <Anchor target="_blank" href="/marketers/docs/implementing-and-using-2fa-login">autenticación de dos factores (2FA)</Anchor> para mantener su cuenta segura frente a accesos no autorizados. |
| <span id="appsflyer-api-and-s2s-tokens"></span><Anchor target="_blank" href="/marketers/docs/managing-appsflyer-tokens">Tokens de AppsFlyer</Anchor> | Utilice tokens de AppsFlyer para autenticar sus llamadas API y S2S. Gestione los tokens y sustitúyalos periódicamente para garantizar la máxima seguridad. |
| <span id="audit-log"></span><Anchor target="_blank" href="/marketers/docs/audit-log">Registro de auditoría</Anchor> | Revise la actividad de la cuenta para identificar accesos no autorizados: inicios de sesión, acciones de gestión de usuarios y llamadas API. |

**Para acceder al Centro de Seguridad:**

* Desde la barra superior, abra el menú de la cuenta (desplegable de dirección de correo electrónico) > **Centro de Seguridad.**
