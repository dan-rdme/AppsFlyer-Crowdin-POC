> **At a glance:** Review and manage the status of all the security-related features of your AppsFlyer account from a single location.

## What can I do from the Security Center?

The **Security Center** provides you with an at-a-glance overview of your AppsFlyer account's security status. Click the button in any section of the **Security Center** to access the following features:

| Feature | Description |
| --- | --- |
| <span id="user-management"></span><Anchor target="_blank" href="/marketers/es/docs/user-management">User management</Anchor> | Create and manage your AppsFlyer users. Assign them permissions to access the features, apps, and data they need. |
| <span id="redirect-allowlist"></span><Anchor target="_blank" href="/marketers/es/docs/set-up-your-domain-redirect-allowlist">Redirect allowlist</Anchor> | Define allowed domains for link redirects. |
| <span id="list-of-authorized-agencies-for-ad-networks"></span><Anchor target="_blank" href="/partners/es/docs/set-up-your-list-of-authorized-agencies">List of authorized agencies</Anchor> (for ad networks) | Manage which agencies you authorize to run campaigns through your network integration. |
| <span id="api-allowlist"></span><Anchor target="_blank" href="/marketers/es/docs/set-up-your-api-allowlist">API allowlist</Anchor> | Define allowed IP addresses for API requests. |
| <span id="enhanced-login-security"></span>Enhanced login security | Configure <Anchor target="_blank" href="/marketers/es/docs/set-up-sso-authentication-with-your-identity-provider-idp">single sign-on (SSO)</Anchor> or <Anchor target="_blank" href="/marketers/es/docs/implementing-and-using-2fa-login">two-factor authentication (2FA)</Anchor> to keep your account safe from unauthorized entry. |
| <span id="appsflyer-api-and-s2s-tokens"></span><Anchor target="_blank" href="/marketers/es/docs/managing-appsflyer-tokens">AppsFlyer tokens</Anchor> | Use AppsFlyer tokens to authenticate your API and S2S calls. Manage the tokens and replace them periodically to ensure maximum security |
| <span id="audit-log"></span><Anchor target="_blank" href="/marketers/es/docs/audit-log">Audit log</Anchor> | Review account activity to identify unauthorized access: logins, user management actions, and API calls. |

* From the top bar, open the account menu (email address dropdown) > **Security center.**
